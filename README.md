# Repositorio de Laboratorios de Redes (ETN1011 - UMSA)

Este repositorio contiene las prácticas oficiales de la materia **Sistemas de Comunicación II** en la Universidad Mayor de San Andrés (UMSA).

## Estructura del Repositorio

- **[`lab01/`](lab01/)**: Laboratorio 1 — Redes Virtuales con Linux (Network Namespaces, interfaces `veth`, subred IPv4 `/30`, diagnóstico ARP e ICMP).
- **[`lab02/`](lab02/)**: Laboratorio 2 — FRRouting en Linux/WSL2 (Plano de Control vs. Plano de Datos, interfaz `dummy0`, `vtysh`, OSPFv2, rutas `blackhole` y equivalencias con Cisco IOS).
