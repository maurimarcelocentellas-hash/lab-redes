===================================================================
GUÍA DE COMANDOS UTILIZADOS EN EL LABORATORIO DE REDES
===================================================================

1. GESTIÓN DE PAQUETES Y SISTEMA
- cd ~ : Cambia al directorio personal del usuario.
- pwd : Muestra la ruta del directorio actual en el sistema de archivos.
- sudo apt update : Actualiza la lista de paquetes disponibles en los repositorios de Ubuntu.
- sudo apt install -y iproute2 iputils-ping traceroute git curl : Instala utilidades esenciales de red y control de versiones.

2. CONFIGURACIÓN DE GIT Y AUTENTICACIÓN SSH
- git config --global user.name "nombre" : Establece el nombre de usuario global para firmar commits.
- git config --global user.email "email" : Establece el correo electrónico asociado a los commits.
- git config --global --list : Muestra las variables de configuración globales activas en Git.
- ssh-keygen -t ed25519 -C "email" : Genera un par de llaves criptográficas SSH para autenticación segura.
- cat ~/.ssh/id_ed25519.pub : Imprime el contenido de la llave pública para registrarla en GitHub.
- ssh -T git@github.com : Prueba la conexión y autenticación segura por SSH con GitHub.

3. DIAGNÓSTICO Y CONECTIVIDAD DE RED
- ip addr show : Lista todas las interfaces de red y sus direcciones IP en el host.
- ip route show : Muestra la tabla de enrutamiento y la puerta de enlace predeterminada.
- ping -c 4 github.com : Envía paquetes ICMP Echo Request para medir latencia y pérdida de paquetes.
- curl -I https://github.com : Realiza una petición HTTP HEAD para consultar únicamente los encabezados del servidor web.

4. CREACIÓN Y CONFIGURACIÓN DE NETWORK NAMESPACES Y VETH
- sudo ip netns add demo-ns : Crea un nuevo espacio de nombres de red aislado (namespace).
- ip netns list : Muestra la lista de espacios de red aislados creados en el sistema.
- sudo ip netns exec demo-ns [comando] : Ejecuta un comando específico dentro del contexto del namespace aislado.
- sudo ip link add veth0 type veth peer name veth1 : Crea un enlace de red virtual de dos extremos (Virtual Ethernet).
- sudo ip link set veth1 netns demo-ns : Mueve un extremo de la interfaz virtual dentro del namespace 'demo-ns'.
- sudo ip addr add [IP/Máscara] dev [interfaz] : Asigna una dirección IP y máscara de subred a la interfaz especificada.
- sudo ip link set [interfaz] up : Activa y enciende la interfaz de red para permitir tráfico.

5. GESTIÓN DE REPOSITORIO Y PUBLICACIÓN
- mkdir -p ~/lab-redes && cd ~/lab-redes : Crea el directorio del laboratorio e ingresa a él.
- git init : Inicializa un nuevo repositorio Git en el directorio actual.
- git branch -M main : Renombra la rama por defecto a 'main'.
- git add [archivos] : Prepara los archivos para incluirlos en el próximo commit.
- git commit -m "mensaje" : Guarda una foto fija del código en el historial local con una descripción.
- git remote add origin [URL_SSH] : Enlaza el repositorio local con el repositorio remoto en GitHub.
- git push -u origin main : Sube las ramas y archivos locales guardados hacia el servidor remoto de GitHub.
