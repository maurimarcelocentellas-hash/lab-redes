1. COMANDOS DE DIAGNÓSTICO DE SISTEMA Y NAVEGACIÓN
- whoami : Muestra el usuario actual en la terminal de Linux.
- uname -a : Muestra detalles del kernel Linux, arquitectura y compilación.
- cat /etc/os-release : Identifica la distribución GNU/Linux y su versión.
- pwd / ls / ls -la : Muestra la ruta actual y lista archivos (incluyendo ocultos).
- cd / cd ~ / cd .. : Navegación por el árbol de directorios del sistema.
- mkdir [dir] / touch [file] : Crea un directorio y un archivo vacío respectivamente.
- cp / mv / rm : Copia, mueve/renombra y elimina archivos en el sistema.
- history | grep [filtro] : Busca comandos ejecutados anteriormente en el historial.

2. HERRAMIENTAS Y CONTROL DE VERSIONES
- sudo apt update && sudo apt install : Actualiza repositorios e instala utilidades.
- curl -fsSL https://opencode.ai/install | bash : Instala el asistente OpenCode en el sistema.
- git config --global user.name / user.email : Configura identidad global en Git.
- ssh-keygen -t ed25519 -C "correo" : Genera claves SSH para autenticación segura.
- ssh -T git@github.com : Prueba la conexión SSH contra los servidores de GitHub.

3. INSPECCIÓN Y DIAGNÓSTICO DE RED
- ip link : Muestra el estado físico y MAC de las interfaces de red.
- ip addr : Muestra las direcciones IP y prefijos asignados a cada interfaz.
- ip route : Muestra la tabla de enrutamiento y la puerta de enlace predeterminada.
- ip neigh : Muestra la tabla de vecinos (caché ARP en IPv4 / NDP en IPv6).
- ping [destino] : Comprueba conectividad ICMP de extremo a extremo.
- traceroute [destino] : Rastrea el salto a salto de los paquetes hacia una IP.
- mtr [destino] : Combina ping y traceroute en tiempo real para diagnóstico de red.

4. VIRTUALIZACIÓN DE RED Y NAMESPACES (TOPOLOGÍA hostA <-> hostB)
- sudo ip netns add [nombre] : Crea un entorno de red aislado (Namespace).
- ip netns list : Lista todos los namespaces activos en el Kernel.
- sudo ip netns exec [ns] [comando] : Ejecuta un comando en el contexto del namespace.
- sudo ip link add vethA type veth peer name vethB : Crea un cable Ethernet virtual de dos extremos.
- sudo ip link set vethA netns hostA : Mueve el extremo vethA al namespace hostA.
- sudo ip link set vethB netns hostB : Mueve el extremo vethB al namespace hostB.
- sudo ip netns exec hostA ip addr add [IP/máscara] dev vethA : Asigna IP a la interfaz en hostA.
- sudo ip netns exec hostA ip link set vethA up : Levanta la interfaz de red en hostA.
- sudo ip netns exec hostA ip link set lo up : Levanta la interfaz loopback local en hostA.
